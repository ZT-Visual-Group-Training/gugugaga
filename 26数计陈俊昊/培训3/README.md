# 培训3 · OpenCV 装甲板灯条识别

## 任务要求

**任务 1（静态图）**

1. 读取装甲板图片
2. 转 HSV
3. 分离 H、S、V 三个通道，分别用窗口展示
4. 写阈值，用 `inRange` 提取红色装甲二值掩膜
5. 保存为 `red_mask.png`

**任务 2（视频）**

1. 处理视频，识别装甲板两侧的灯条
2. 用最大外接矩形框住灯条
3. 在图像上显示四个角点，并连接装甲板的四个角点
4. 输出处理后的视频

## 编译

依赖：OpenCV 4.x（Ubuntu 下 `sudo apt install libopencv-dev`）

```bash
cd 培训3
mkdir -p build && cd build
cmake ..
make
```

## 运行

⚠️ 必须在 `培训3/` 这一层执行，因为 `assets/` 是相对路径。

```bash
cd 培训3
./build/app                          # 默认读 assets/114514.mp4
./build/app 输入视频.mp4 输出视频.mp4   # 也可以指定
```

窗口里按 **ESC** 退出（中途退出会导致视频写不完整）。

## 实现思路

### 1. 红色掩膜

红色在 HSV 里跨 0° 两侧，OpenCV 的 H 范围是 0~180，所以取 `165~180` 这一段。

```
HSV 下限 (165, 100, 100)    上限 (180, 255, 255)
```

`V` 下限取 100 是个折中：取 0 会把灯条外围的暗红光晕也算进去（点会浮在外面），
取 170 又会缩进灯条亮芯内部（点往内缩）。

掩膜出来后做两步形态学：

- `MORPH_OPEN`（3×3）：去掉零散小白点
- `MORPH_CLOSE`（5×5）：补上灯条上的断口

### 2. 筛灯条

对每个轮廓取外接矩形，用三个条件筛：

| 条件 | 值 | 作用 |
|---|---|---|
| 面积 | 1000 ~ 25000 | 挡住噪点和大块反光 |
| 高宽比 | > 2.0 | 灯条细长，挡住方白块 |

⚠️ **不要加宽度上限**。实测加 `width < 75` 会让 570 帧里的 185 帧配不出对
（灯条在某些角度会变宽），视频会出现几秒空白。

### 3. 配对

两根灯条像同一块装甲板的条件，全部用**比例**而不是绝对像素
（灯条在视频里大小一直在变）：

```cpp
std::max(h1, h2) / std::min(h1, h2) < 1.5     // 高度接近
std::abs(a.y - b.y) < 0.4 * min(h1, h2)        // 顶边接近
```

有多组候选时，取"高度差 + 顶边差"最小的那一对，只画一组。

### 4. 四个角点（关键）

**不能用 `boundingRect` 的角。** 它是轴对齐的外接矩形，灯条一斜，
框就比灯条宽，四个角落在空气里。

正确做法是从**轮廓**上取极值点：

| 角 | 条件 | 含义 |
|---|---|---|
| 左上 | `x + y` 最小 | 最靠左上 |
| 右上 | `x - y` 最大 | 最靠右上 |
| 右下 | `x + y` 最大 | 最靠右下 |
| 左下 | `x - y` 最小 | 最靠左下 |

这四个点必定落在轮廓上，所以天然贴合灯条。

### 5. 画框

- **黄框**：单根灯条的外接矩形（`boundingRect`）
- **绿框**：连接四个极值点的闭合四边形
- **绿点**：四个角点实心圆

## 效果

- 任务 1：`red_mask.png` —— 只有灯条是白色，装甲板和背景全黑
- 任务 2：`result.mp4` —— 每根灯条一个黄框，整体一个绿框，四个角点标在灯条端点

## 踩过的坑

| 坑 | 现象 | 解法 |
|---|---|---|
| `cmake..` 没空格 | `command not found` | `cmake ..` |
| 在 build 里跑 `./app` | 读图失败 | 回项目根跑 `./build/app` |
| 视频只写了几秒 | 输出 mp4 帧数不足 | 窗口里别按 ESC |
| 框抖 | 角点每帧乱跳 | 用极值点而不是 `minAreaRect`（后者对毛刺极敏感） |
| 点浮在灯条外 | 落在暗红光晕上 | 提高 `V` 下限 |
